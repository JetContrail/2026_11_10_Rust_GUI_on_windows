# 操作マニュアル

## 下絵を読み込む
1. **ファイル → 画像を開く** (Ctrl+O) で PNG / JPEG / BMP を選びます
2. 画像は「下絵」レイヤーに表示され、キャンバスは画像と同じサイズになります (最大 4096×4096 px)
3. 下絵は編集できません。消しゴムや範囲消去は描画レイヤーにだけ作用します
4. 読み込みは元に戻す (Ctrl+Z) で取り消せます

## 描く
- 左のツールパレットで **ペン** を選び、キャンバス上をドラッグすると自由線、クリックすると点を描きます
- ドラッグ中に **Shift** を押している間は、Shift を押した位置からカーソルまでの直線になります。Shift を離すと直線が確定し、そのまま自由線を続けられます (全体で 1 回の Undo 単位)。消しゴムでも同様です
- **直線** ツールでは、押した位置が始点、離した位置が終点の直線を描きます (ドラッグ中はプレビュー表示)
- **線幅** は 1 / 2 / 4 / 8 / 16 / 32 px から選びます
- **色** はカラーボタン (ピッカー)、R / G / B スライダー、パレットのいずれかで選びます

## 文字を入れる

- **テキスト** ツールを選び、キャンバス上の文字を置きたい位置をクリックすると入力欄が開きます。文字はクリックした位置を左上として描かれます
- 日本語は IME (変換中の文字も入力欄に表示) で入力できます。Enter で改行、**Ctrl+Enter** または入力欄の外 (キャンバス) をクリックで確定、**Esc** で取消です。確定した文字は 1 回の Undo 単位です
- **文字サイズ** は数値 (8〜400 px) を入力するか、12 / 16 / 24 / 32 / 48 / 64 / 96 のボタンで選びます
- **フォント選択…** でインストール済みのフォント一覧から選べます (検索・プレビュー付き)。選んだフォントに無い文字は、游ゴシックなどの標準フォントで表示されます
- 色は現在の描画色です。確定後の文字の再編集・移動はできません (Undo で取り消してください)

## 消す
- **消しゴム**: ツールを選んでドラッグします。サイズは「消しゴムサイズ」で選びます
- **範囲消去**: **範囲選択** でドラッグして矩形を選び、Delete キー (または **編集 → 選択範囲を削除**) を押します。Esc で選択解除します

## 表示
- Ctrl+マウスホイールで拡大・縮小 (10%〜3200%)。**表示** メニューの拡大 / 縮小 / 100% も使えます
- キャンバスが画面より大きいときは、スクロールバー、ホイール (縦)、Shift+ホイール (横)、中ボタンドラッグで移動します
- 右のレイヤーパネルのチェックで各レイヤーの表示を切り替えます

## 元に戻す / やり直し
- Ctrl+Z で元に戻す、Ctrl+Y でやり直します (それぞれ 100 回まで)
- ステータスバーに残り回数が表示されます

## 保存・書き出し
| メニュー | 内容 |
|---|---|
| 保存 (Ctrl+S) / 名前を付けて保存 | `.paint` 形式で保存。下絵画像・描画内容・色・線幅・キャンバスサイズを含みます |
| プロジェクトを開く | `.paint` を開きます。壊れたファイルは読み込まず、現在の内容を保持します |
| PNG 書き出し (表示中レイヤー) | 表示中のレイヤーを合成した PNG |
| 透過 PNG 書き出し (描画レイヤーのみ) | 下絵を除いた、背景が透明な PNG |

未保存の変更があるとタイトルバーに `*` が表示されます。この状態で終了 (ウィンドウを閉じる / **ファイル → 終了**) またはプロジェクトを開こうとすると、「保存 / 保存しない / キャンセル」を確認します。
